# Mind Space – Notes, Tasks and Focus Tracker

A productivity-focused full-stack web application designed to help users manage tasks, notes, and focus sessions efficiently.

## Live Demo
[Open Project](https://mind-space-focus-tracker.vercel.app/)

## Features
- Task management
- Notes organization
- Focus timer / Pomodoro tracker
- Responsive user interface
- Persistent data storage

## Tech Stack

### Frontend
- React
- JavaScript
- CSS
- Vite

### Backend
- Node.js
- Express.js

### Database
- MySQL

## Project Structure
- frontend/ → React frontend
- backend/ → Express backend API
